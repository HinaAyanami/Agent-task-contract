# SortLab — 单文件排序算法可视化

冒泡/插入/快速/归并四种排序的逐步动画，实时统计比较与写入次数。
单文件 `index.html`（内联 CSS/JS，无 CDN、无外部资源、无网络请求），双击即可离线运行。

## 运行

直接双击 `index.html`，或用浏览器打开；不需要安装依赖或启动本地服务器。

## 控件

| 控件 | 作用 |
| --- | --- |
| 算法下拉 | 切换四种算法；切换时数组不变，便于对比计数 |
| 开始 / 暂停 | 播放或暂停；完成后变为「重新开始」并重新生成数组 |
| 单步 | 每次前进一条步骤（一次比较或一次写入） |
| 重置 | 按当前规模重新生成随机数组，回到就绪态 |
| 速度滑块 | 1–10 档，每帧 1 → 256 条步骤 |
| 规模滑块 | 20–200 个随机整数（取值 4–100） |

## 视觉与状态

- 柱高对应数值，颜色由冷到暖表示数值由小到大；白色柱＝正在比较或写入的元素。
- 排序完成后所有柱子转为绿色。
- 状态不只靠颜色：顶部「状态」卡片和图表下方摘要都用文字说明（就绪/运行中/已暂停/已完成）。
- 1280×800 与 800×600 视口下均无横向滚动。

## 实现要点

- 算法只有一份：`<script id="sort-core">` 内的纯函数，浏览器里挂到 `window.SortCore`；
  每个算法返回 `{ sorted, comparisons, writes, steps }`，`steps` 记录比较（c）与写入（w）。
- 先算完整步骤序列再按帧回放，动画、单步、统计因此天然一致。
- `selftest.js` 用正则抽取该脚本并以 `new Function` 执行，不复制第二份实现；每条用例独立重放
  `steps` 还原数组并与 `sorted` 比对，同时独立重算比较/写入次数。
