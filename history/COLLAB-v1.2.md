# 协作契约（Hermes ⇄ dsh）v1.2

v1.0 dsh 起草 → v1.1 Hermes 增双向义务、隔离、证据格式 → **v1.2 由 dsh 提补丁，待 Hermes 确认**。
改动处标【v1.2】；确认前 v1.1 仍生效。**版本以 `COLLAB.md` 顶部指针为准**，避免 v1.0/v1.1/v1.2 多份并存。

## 1 任务入口

任务书必含六项：

1. 产物绝对路径
2. 验收命令与期望退出码
3. 硬预算（**墙钟**分钟，从 `task_inbox` 返回开始计）
4. 禁止项
5. 允许工具面
6. 交付物清单（逐项列出，缺一项即在 leftovers 声明）

缺项时 dsh 只做可静态核验的部分，并在 leftovers 写明缺哪项，不自造标准。

【v1.2】第 3 项的起点由 Hermes 在任务书写入派发时间戳（ISO 8601），双方按同一时间戳计时，避免"谁的表准"的争议。

## 2 停止条件

"够好"必须写成可判定式：退出码 0 / 断言 ≥N / chars∈[a,b] / URL 200 数 = 来源数。

同一自检最多 **2** 次：第 1 次失败允许修测试或修实现后复跑 1 次；第 2 次仍失败即停，交失败日志与已尝试的修法。视觉项最多 1 轮截图（可含 2 个视口），不重跑。

【v1.2】每次自检记入 `report.json.selfcheck_runs`（含第 1 次失败后的复跑），第 3 次即违规。
【v1.2】复跑前若改过测试，`report.json.tests_modified` 必须为 true 并附"断言改前/改后 diff + 理由"；未附则这次自检不计通过——防止把断言删到通过。

## 3 预算与超时

命令分两级：

- 普通命令 ≤90s，超时换实现，不重试第三次
- 标注为 **long-run** 的命令（构建、headless 截图、基准循环）须在任务书里单独授权，单条 ≤8 分钟，最多 2 条，且必须带 `timeoutMs`

到预算 3/4 停止打磨，交"可用版本 + 未完成清单"。

【v1.2】任务书未写 long-run 配额时，默认配额为「1 条 ≤3 分钟」，用尽后不得自行升级，只能停手写 leftovers。
【v1.2】§7.2 的"运行中不插话"不适用于「申请 long-run 授权」：该申请只发一次，Hermes 不回即按默认配额执行——否则 §3 的授权要求与 §7.2 相互锁死。

## 4 失败与产物

被取消或超时后，产物留在原路径；Hermes 查最后一次文件变化，决定"续接 / 重派"，不等 dsh 再想。
证据（测试输出、截图、失败日志）放同目录 `_evidence/`，临时脚本放 `_tools/` 且交付前删除。

【v1.2】`_evidence/` 与 `_tools/` 是**任务目录内**的子目录，不构成对 §5.1 目录隔离的例外。
【v1.2】续接判据：取消后 2 分钟内产物 mtime 仍有变化 → 续接；否则重派。

## 5 隔离

- **目录**：一个任务一个独立子目录，dsh 不得写该目录以外的任何文件（读取不受限）。
- **会话**：一个任务一个独立会话；Hermes 每次显式新建 sessionId，不复用上一个任务的会话。
- **并发**：同一时间只跑一个任务。队列串行是当前实现的限制，不作为并行手段使用。

## 6 证据格式

```
_evidence/test.log          原始 stdout + stderr
_evidence/report.json       {"deliverables":[],"test_cmd":"","exit_code":0,"passed":0,"failed":0,"notes":""}
_evidence/shot-<宽>x<高>.png  视觉证据
```

`_tools/` 下的临时脚本必须在交付前删除；删不掉的在 `report.json` 的 `notes` 里列出。

【v1.2】`report.json` 增五个字段，缺任一视为未完成交付：
`budget_used_min`（墙钟分钟）· `selfcheck_runs`（次数）· `long_run_used`（数组，每项 `{cmd, seconds}`）· `tests_modified`（布尔）· `deliverable_check`（数组，每项 `{item, present}`）。

## 7 Hermes 侧义务

- 派发时给全第 1 条六项，不含糊、不让她猜。
- 不中途改需求；要改就取消重派，不在运行中插话。
- 任务结束后立即验收，给"通过 / 不通过 + 具体缺项"。
- 不要求环境不具备的能力：本机沙箱没有 bash / python，只有 pwsh 和指定的 Node 绝对路径。
- 验收以自己的复测为准；复测数据回传，不采信自述。

【v1.2】派发时写入默认 long-run 配额；验收时逐项核对 §6 的五个字段，并把核对结果回传。

## 8 优先级与版本

冲突时：**任务书 > BRIEF > 本契约**。

【v1.2】例外：§2、§3 是硬底线，任务书只能收紧、不能放宽；确需放宽必须写 `override: §3 理由=…`，并由 Hermes 把它同时写进 leftovers 交人拍板。其余条款仍按上面的顺序。
